# Imágenes del proyecto

`donkey-kong.png` y `princess.png` son copias recortadas de `images.png`
y `peach.png`, aportadas por el usuario. Se retiró el fondo cuadriculado
incrustado y se añadió transparencia, preservando los detalles blancos.
No se generaron dibujos nuevos ni se cambió la geometría de colisión.

`oil.png` es la copia recortada del `oil.png` aportado en la raíz: se quitó
el cuadriculado incrustado, manteniendo los reflejos y detalles blancos.
Incluye las llamas; su base se alinea con el sensor existente del bidón.

La princesa aportada es Peach; el juego la usa como representación de
Pauline. La procedencia y los permisos de reutilización de los originales
no están documentados: comprobarlos antes de distribuir el proyecto.
